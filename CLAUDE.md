# rohan2010.github.io

Rohan Pant's portfolio: Next.js 16, static export to GitHub Pages. Read `AGENTS.md` before writing Next.js code.

## Content rules (always)

- **Writing for the Notebook** (`/notebook/`, blog posts): use the `notebook-post` skill. Interview Rohan before drafting, and never invent an experience, a result, a number or a mistake.
- **Building for the Playground** (`/playground/`, landing-page components plus their prompts): use the `playground-item` skill. Web UI only: no project-specific pieces, and no image, video or writing prompts.
- **Never put on the site:** the name of Rohan's employer (write "my day job"), or 21st.dev or any component gallery as a source or credit.
- **Colours and fonts** come from the site's tokens only (Tobacco & Brass; Instrument Sans and Serif, JetBrains Mono). Notes and callouts are fully bordered boxes, never a tint with a left accent bar.
- **Voice:** plain, dry, short sentences, no hype words. Keep Rohan's own wording when editing his text.
- **Before saying content is done:** `npm run check`, `npx next build`, then look at it in a real browser at desktop and phone width.
- **Commits** never carry Claude attribution.
